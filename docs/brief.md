## Ключевые цели брифа (что Тимур попросил исходно)

1. **Persona-сайт** — портфолио, заменяющее резюме. Точка входа для входящих
   запросов на AI-консалтинг и founding AI engineer позиции.

2. **KPI** (3 месяца): 5+ входящих запросов, 2+ контракта, попадание в выдачу
   Google по 2-3 целевым запросам, ссылка работает в outreach.

3. **Позиционирование** — AI-архитектор для B2B-команд. Главный угол:
   «помогаю командам построить процессы, в которых AI работает за вас».
   После brainstorm-сессии 2026-05-19 → вариант B (spec-driven AI) с
   битами из A и C. См. `decisions/D-001-positioning.md` (создаётся).

4. **Целевая аудитория** — 3 профиля: founder B2B-стартапа (5-50 чел.),
   технический руководитель средней компании, сооснователь AI-стартапа.

5. **Структура** — одна страница, 9 секций (Hero · О тебе · Принципы ·
   Кейсы · Карта компетенций · Стек · Куда расту · Кому подхожу · Контакты).
   В brainstorm выбран proof-first порядок (Кейсы сразу после Hero).

6. **Стиль** — простой русский, без англицизмов где есть русский эквивалент.
   Словарь замен зафиксирован в [`../SPEC.md` §8](../SPEC.md#8-контент-стратегия).

7. **Эстетика** — Vercel-территория. Тёмная база + один акцентный цвет,
   шрифт без засечек (Inter/Geist), много пустоты, мало декора.
   В brainstorm выбран mood «A» (dark gradient + grid + mono).

8. **Стек** — Next.js или Astro. После обсуждения выбран **Astro**
   (см. `decisions/D-002-tech-stack.md`, создаётся).

9. **Доменный бюджет** ≤ $100/год. Зоны .ai / .dev / .tech / .ru / .work.

10. **Метрики производительности** — Lighthouse ≥ 95, LCP < 1.5s,
    мобильная вёрстка обязательна.
