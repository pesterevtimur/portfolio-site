# Analytics — Plausible vs Vercel Analytics

> Цель: выбрать одну систему аналитики. Без Google Analytics (медленный, не нужен).

## Критерии

1. Скорость загрузки скрипта (KB и ms)
2. Стоимость
3. GDPR-совместимость / подход к cookie
4. Доступность в РФ
5. Качество данных для KPI из SPEC §4 (входящие запросы, CTA конверсия)
6. Простота настройки в Astro

## Сравнение

| Критерий | Plausible | Vercel Analytics |
|---|---|---|
| Скорость скрипта | ~1 KB — в 54 раза меньше GA (экономия ~135 KB/посетитель) | Несколько KB; загружается со стороны Vercel CDN, рядом с хостингом — минимальная задержка |
| Стоимость | $9/мес (Starter, до 10k pageviews) — платно с первого дня; годовая подписка даёт 2 месяца скидки | Бесплатно (Hobby): 50 000 событий/мес; Pro: $3 за каждые 100k событий сверх лимита |
| GDPR / cookie | Cookie-free by design; данные не покидают ЕС (EU-hosted); баннер cookie **не требуется** | Cookie-free; идентификация через однодневный hash запроса, не хранящийся между днями; соответствует GDPR без cookie-баннера |
| Доступность в РФ | Сайт plausible.io доступен из РФ; **оплата картой РФ** — высокий риск отказа из-за санкционных ограничений Stripe/Paddle (по состоянию на 2026-05-19, официальной позиции нет, но практика 2022+ подтверждает проблему) | Vercel (Hobby) **бесплатен** — платёжная карта не требуется; доступ к дашборду через веб без ограничений |
| Данные для KPI | Pageviews, рефереры, страны, устройства, bounce rate; цели и конверсии (в т.ч. CTA-клики) доступны на всех платных планах | Pageviews, рефереры, страны, OS, браузеры, bounce rate; кастомные события (CTA-клики) — только на Pro; UTM-параметры — только Web Analytics Plus ($10/мес) |
| Astro-интеграция | Нет официального Astro-интеграционного пакета; подключение через ручной `<script>` в `<head>` — работает, но менее элегантно | Официальный пакет `@vercel/analytics` с Astro-компонентом (`import Analytics from '@vercel/analytics/astro'`); нативная поддержка роутинга |
| Отчётное окно | Без ограничений (все данные хранятся бессрочно) | Hobby: 1 месяц; Pro: 12 месяцев |

## Рекомендация

**Выбрать: Vercel Analytics (Hobby tier).**

Обоснование:

1. **Бесплатно до 50 000 событий/мес** — для портфолио с несколькими сотнями pageviews в первые месяцы запаса более чем достаточно. Plausible стоит $9/мес с первого дня.

2. **Нет проблемы с оплатой из РФ.** Plausible — платный сервис, российские карты в 2022–2026 массово отклоняются международными платёжными процессорами. Vercel Hobby-план не требует оплаты вообще.

3. **Нативная Astro-интеграция.** Официальный пакет `@vercel/analytics` имеет компонент для Astro с поддержкой маршрутизации «из коробки». У Plausible нет официального Astro-пакета — только ручной `<script>`.

4. **Нулевая дополнительная инфраструктура.** Сайт уже хостится на Vercel; аналитика включается одной кнопкой в дашборде + 3 строки кода.

**Честный плюс Plausible, которого нет у Vercel Analytics:**
- Данные гарантированно хранятся в ЕС (EU-first) — для Vercel расположение зависит от региона деплоя.
- Отчётное окно не ограничено даже на бесплатном использовании (self-hosted). На Hobby Vercel данные видны только за последний месяц.
- Скрипт меньше (~1 KB vs несколько KB).

Эти преимущества не перевешивают барьер оплаты и отсутствие Astro-интеграции на текущем этапе.

## План настройки (Vercel Analytics)

### Шаг 1. Включить Web Analytics в Vercel Dashboard

1. Открыть [vercel.com/dashboard](https://vercel.com/dashboard) → выбрать проект.
2. В левом сайдбаре нажать **Analytics**.
3. Нажать кнопку **Enable** в заголовке раздела.

### Шаг 2. Установить пакет

```bash
npm install @vercel/analytics
```

### Шаг 3. Добавить компонент в базовый лейаут Astro

Открыть `src/layouts/BaseLayout.astro` (или эквивалентный файл с `<head>`):

```astro
---
import Analytics from '@vercel/analytics/astro';
// ... остальные импорты
---

<html lang="ru">
  <head>
    <meta charset="utf-8" />
    <!-- ... мета-теги -->
    <Analytics />
  </head>
  <body>
    <slot />
  </body>
</html>
```

> Компонент `<Analytics />` доступен начиная с `@vercel/analytics@1.4.0`.

### Шаг 4. Деплой

```bash
vercel deploy
# или git push — если подключён Git-репозиторий к Vercel
```

После деплоя в Network-вкладке браузера должен появиться XHR-запрос на `/_vercel/insights/view`.

### Шаг 5. Проверить данные

- Открыть дашборд проекта на Vercel → **Analytics**.
- Данные начнут появляться после первых реальных посещений (не localhost).

### Шаг 6. Отслеживать CTA-клики (при необходимости, Pro)

На Hobby-плане кастомные события недоступны. Когда трафик вырастет и потребуется отслеживать клики по CTA:

```bash
# Перейти на Pro ($20/мес за команду) — только тогда, когда нужно
```

```astro
---
import { track } from '@vercel/analytics/astro';
---

<button onclick="track('cta_click', { page: 'home' })">
  Оставить заявку
</button>
```
