## Приоритетные запросы (3-5)

Критерии отбора: высокая транзакционность (человек готов нанять) + средняя конкуренция (реально попасть в топ без ссылочного пузыря) + соответствие позиционированию B (spec-driven AI-архитектор для B2B).

### 1. «ИИ консультант для стартапа»

**Почему:** Точное попадание в Профиль 1 (founder B2B-стартапа, 5-50 чел.) и Профиль 2 (tech-lead, которому «нужен внешний взгляд»). Поиск выдал живые агентские страницы, но ни одного персонального сайта — наш зазор. Конкуренция средняя: побеждают компании, а не персоны.

**Где использовать:** `<title>`, `<meta description>`, H1 на Hero-секции (в той или иной форме).

### 2. «AI аудит для стартапа»

**Почему:** Сигнал чёткой транзакционности — человек ищет конкретную услугу, а не статью. Конкуренция средняя: есть несколько агентских страниц (genai-lab.ru, scriptogenerator.ru), но персонального специалиста нет ни одного. Хорошо ложится в позиционирование — «аудит» = «внешний взгляд, чёткое ТЗ, проверки».

**Где использовать:** `<meta description>`, секция «Кому подхожу».

### 3. «AI-консультант B2B»

**Почему:** Самая высокая ожидаемая частотность из транзакционных. Конкуренция чуть выше (add-one.ru, aiconsult.pro), но по-прежнему нет персональных сайтов в выдаче. Прямо соответствует ориентиру из SPEC §4.

**Где использовать:** Open Graph title, `<title>`, первый абзац «О себе».

### 4. «нанять AI архитектора»

**Почему:** Узкий запрос с очень низкой конкуренцией — реальный шанс занять первую страницу даже без ссылочной массы. Частотность меньше, но намерение идеальное: человек уже принял решение нанять и выбирает специалиста.

**Где использовать:** `<meta description>`, якорный текст в outreach-сообщениях.

### 5. «Тимур Пестерев AI»

**Почему:** Брендовый запрос — сейчас нулевая конкуренция. Через 1-3 месяца после outreach-рассылок часть получателей будет гуглить по имени. Важно, чтобы сайт был первым результатом. Включается в `<title>` + Open Graph автоматически через имя автора на странице.

**Где использовать:** `<title>` (имя в конце), `alt` у портретного фото, `<meta author>`.

## План размещения ссылки

### Где будем размещать

- **Telegram-сообщения (outbound):** да. Основной канал по SPEC §4. Каждое холодное сообщение содержит ссылку на сайт как замену «скинь резюме».
- **Подпись в холодных письмах:** да. Короткая строка: «Тимур Пестерев — AI-архитектор для B2B [ссылка]» в подписи email.
- **LinkedIn профиль:** да. Ссылка в About-секции и в Featured. Пассивный канал — не требует усилий, но даёт контекст при проверке профиля.
- **Habr / vc.ru:** v2-кандидат. В MVP нет публикаций — ссылка некуда идти. При появлении первой статьи (v2) — добавить ссылку в bio автора.
- **GitHub профиль (README.md):** да, если профиль публичный. Один раз, без усилий.

### Где НЕ будем

- **Spam-каталоги, сайты ссылочных агрегаторов** — не делаем. Риски для репутации домена без SEO-пользы.
- **Reddit / Product Hunt / HackerNews flood** — не делаем. Аудитория не русскоязычная, присутствие без контента воспринимается как спам.
- **Telegram-канал:** нет канала — нет размещения (см. SPEC §11 — канала пока нет).
- **Автоматический постинг в тематические группы** — не делаем. Без полезного контента — бан и репутационный вред.
