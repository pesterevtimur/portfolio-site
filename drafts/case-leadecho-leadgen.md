## Заголовок
leadecho-leadgen · Мультиагентная система холодных продаж для B2B SaaS

## Контекст (~50 слов)

LeadEcho.ru — B2B SaaS-стартап: LLM-аналитика 100% звонков отдела продаж, автозаполнение CRM, коучинг менеджеров. Задача: выстроить воспроизводимый процесс холодного охвата с нуля — без бюджета на специалиста по outreach и без ошибок уровня «отправить спам». Первый целевой сегмент — 172 дилера спецтехники с ростом выручки +15% за 2023–2025.

## Что построил (~100 слов)

Мультиагентный репозиторий с жёстким разделением ролей: Claude Desktop — архитектор и бизнес-аналитик; Claude Code — исполнитель и QA; Codex CLI — adversarial reviewer; Timur — финальный approver и единственный, кто нажимает «отправить». Источником правды служит SPEC.md: любое отклонение требует ADR, а не молчаливого дрейфа. Четыре закона проекта блокируют самоодобрение черновиков, выдуманные метрики и нецелевые изменения. Для сегмента A1 написан ICP-бриф с adversarial-проверкой, портированы 11 playbook-страниц по методологии холодных продаж для российского B2B-рынка. Шаблон письма опирается на подтверждённый кейс из KP: дилер +9,2% AOV, ROI 24×.

## Результат (~80 слов)

Текущий статус: playbooks написаны и прошли Codex-review (3 批 × adversarial-проверка, 28+ issues зафиксированы и закрыты), ICP-бриф для сегмента A1 завершён, шаблон письма в работе. Воспроизводимый процесс: следующий сегмент (A2, 136 компаний) разворачивается по тем же правилам без повторного проектирования. Я выступаю как owner всей системы: пишу законы, расставляю агентов, принимаю решения — но не верстаю вручную каждое письмо.
